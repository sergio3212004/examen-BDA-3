# Shared UI components

The project uses custom Vue components rather than a primitive component library. Most study views are feature-level components. The only shared interactive shell component is documented in `layouts.md`.

Reusable visual primitives are CSS classes defined in `src/style.css`: `.primary`, `.outline-button`, `.eyebrow`, `.section-heading`, `.progress`, `.theme-workspace-nav`, cards, tab rows, diagram stages, and quiz controls.
